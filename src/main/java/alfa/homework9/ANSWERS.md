1. Нужно ли было впринципе писать свой собственный генератор с фамилиями? Было бы проще использовать генератор из datafaker?
Имеет смысл писать свой собственный генератор с фамилиями, если необходимы какие-то конкретные фамилии. Но чаще всего
можно использовать уже написанный генератор.
2. Какая из двух библиотек из этого задания может больше пригодится при написании автотестов - jfiglet или datafaker?
datafaker, в автотестах часто необходимо генерировать данные, а красивый вывод нужен не часто.
3. Каким образом JAR-файлы этих библиотек попали к нам в проект?
При добавлении зависимости в POM.xml Система сама скачает нужные JAR-файлы и добавляет его в classpath проекта при копиляции.
