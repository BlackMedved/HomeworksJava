1. heroesCreated должен быть статическим потому что это поле принадлежит всему классу. То есть мы должны считать
количество созданных героев, а не у каждого героя что-то.
2. name, health и level не статические потому что это свойства каждого отдельно созданного героя, а не всех вместе.
3. printHeroesCreated() можно вызвать без создания объекта потому что этот метод принажлежит всему классу, а не
конкретному экземпляру.
4. Статические методы могут работать только со статическими полями, потому что такие методы можно вызвать без создания
экземляра класса. Иначе у нас ещё не будут инициализированы нестатические поля и возникнет ошибка.
5. Если к классу Hero добавить ключевое слово final это запретит наследование этого класса, а поскольку у нас уже
определены наследники класса Hero произойдет ошибка при компиляции.
6. Переменные имеют тип Hero, но вызывают версии метода attack() из конкретных наследников потому что мы создали
экземляры классов конкреных наследников, а объеденины они в массиве типа Hero. Таким образом происходит пример
полиморфизма: разные реализации вызываются одинаковым методом.
7. Переменная knight имеет модификатор final но ее поля могут быть изменены потому что final запрещает менять ссылку на
объект, а сами поля могут быть изменены.
