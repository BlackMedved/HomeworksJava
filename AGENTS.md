Проект HomeWorks - учебный проект по изучению Java для QA автоматизатора.

test\java\alfa\homework17 и test\resources\features — учебный набор API-тестов для тренировочного магазина ServeRest
(https://serverest.dev).

Стек: Java 25, maven 4.0.0, JUnit 5 (Jupiter), RestAssured 5.5.6, Jackson 2.20.0 (сериализация DTO), Hamcrest (матчеры).

Пишем тесты только на Java 25. Если потребуется написать на другой версии, запроси разрешение.
